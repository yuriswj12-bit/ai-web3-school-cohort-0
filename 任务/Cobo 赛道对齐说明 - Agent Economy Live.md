# Cobo 赛道对齐说明 - Agent Economy Live

**项目名称**：Agent Economy Live  
**赛道**：Cobo Agentic Economy × Cobo Agentic Wallet (CAW)

## 1. 项目中 AI Agent 如何使用 CAW

我们将 **预测下注层（Prediction Betting Layer）** 作为核心资金流场景，让 Agent 能够在可控边界内持有资金、执行支付和接收报酬。

**具体使用方式**：

- **Agent 钱包持有**：每个参与预测市场的 Agent 都拥有一个独立的 **CAW（Cobo Agentic Wallet）** 作为资金账户。
- **预算管理**：Agent 可设置**每日/单笔预算上限**、允许支付的对象白名单、以及资金用途标签（例如「购买数据」「支付推理服务」「下注预测」）。
- **执行支付/交易**：当用户（人类或其他 Agent）对某个 Agent 的未来表现进行下注时，资金通过 CAW 完成托管与结算。获胜的 Agent 可自主或按规则接收 CAW 转账。
- **资源采购场景**（扩展方向）：未来可让 Trading Agent 或 Research Agent 使用 CAW 自主支付数据源、API 调用、GPU 算力等资源。

## 2. 风险边界控制与记录

我们设计了以下机制来确保 Agent 在**可控边界**内操作资金：

| 风险维度     | 控制方式                                   | 记录方式               | 说明                           |
|---------------------|--------------------------------------------------|----------------------------------|------------------------------------|
| **支出上限** | CAW 设置单笔 / 日预算上限      | 链上 + CAW 后台日志      | 防止 Agent 过度花费         |
| **支付对象限制** | 白名单机制（仅允许特定 Agent / 服务地址） | CAW 权限配置 + 事件日志  | 避免向未知地址转账     |
| **用途限制**     | 资金用途标签（Budget Tag）               | 每次交易带 Tag 上链      | 区分「下注」「采购」「分润」 |
| **时间窗口**     | 设置有效期（例如预测市场只在特定时间段开放） | 智能合约 + CAW 时间锁   | 防止长期占用资金       |
| **权限隔离**     | Agent 只能在授权范围内签名交易         | CAW 权限策略 + 多签/阈值机制 | 降低私钥/权限泄露风险 |
| **异常监控**     | 异常大额交易 / 高频操作告警           | CAW 风控系统 + 项目后台监控 | 实时发现异常行为         |

** 风险边界记录方式**：
- 所有资金操作均通过 CAW 完成，交易记录、权限变更、预算调整全部可追溯。
- 关键事件上链（预测下注、结算、Agent 收益到账），同时在项目后端记录操作日志，便于审计和复盘。
- Demo 时可展示「Agent 设置预算 → 下注 → 结算 → 资金到账」的完整链路，并展示 CAW 后台的权限与风控配置。

## 3. 与 Cobo 赛道核心要求的对齐

- **场景贴合度**：项目核心是让人类和 Agent 能对 Agent Economy 中的服务进行经济判断和资金博弈，CAW 是资流转的**关键基础设施**，而非可替换的展示元素。
- **资金流程完整度**：从「用户/Agent 发起预测 → CAW 托管资金 → 结果出来后自动结算 → 胜出 Agent 收到报酬」，形成完整闭环。
- **可演示性**：Week 4 MVP 可通过 Mock + CAW 测试网地址演示完整资金流（或使用 CAW 的 Sandbox 模式）。
- **风险边界说明**：已在本文档中明确列出支出上限、对象白名单、用途标签、时间窗口、权限隔离等控制手段。
