# Scope Review - Agent Economy Live（Week 4 范围控制）

**项目目标**：在 Week 4 交付一个**可稳定演示、视觉击力强**的 MVP，重点展示「Agent Economy 的实时可视化 + CAW 资金流」。

## 本周明确**不做**或**延后**的功能（至少 3 项）

| 序号 | 功能 / 特性 | 处理方式 | 理由 | Week 4 替代方案 |
|------|-------------|----------|------|-----------------|
| 1 | **真实 CAW 链上资金流完整闭环**（包括真实下注、自动结算、智能合约托管） | **改成 Mock + Sandbox 模拟** | CAW 真实集成复杂度高，时间极度紧张，容易导致核心 Demo 流程不完整 | 使用 CAW Sandbox / 测试网模拟资金操作流程，重点展示「Agent 设置预算 → 下注 → 结算 → 到账」的完整视觉链路 + 权限边界说明 |
| 2 | **高频实时 WebSocket Subscription**（交易流毫秒级实时推送） | **延后 / 改成 Polling + 动画模拟** | 实现稳定、高性能的实时推送需要较多调试时间，容易影响其他核心功能 | 前端使用定时轮询 + 动画模拟实时效果，关键数据（排行榜、Agent 历史）使用真实查询 |
| 3 | **多链支持**（同时支持 Ethereum + Base + 其他链） | **砍掉** | 多链会大幅增加索引和数据一致性工作量，超出 Week 4 可控范围 | Week 4 只聚焦 **Ethereum / Base** 其中一条链，优先保证数据质量和 Demo 流畅度 |
| 4 | **复杂 AI Agent 自主决策模块**（让 Agent 自己分析数据后自动下注） | **延后** | 这属于进阶功能，开发和调试成本高，容易导致范围失控 | Week 4 聚焦「人类 + 其他 Agent 可以对 Agent 进行预测下注」，自主决策留到后续迭代 |
| 5 | **高级可视化**（Three.js 3D 场景、复杂粒子特效、沉浸式大屏） | **改成 2D + 适度动画** | 高级可视化开发时间长，且对核心功能帮助有限 | 使用 Recharts + Framer Motion 实现清晰、美观、流畅的 2D 实时更新效果 |

## Scope Review 总结

**周 4 核心交付物**（必须完成）：
- 实时/准实时活动流 + 动态排行榜
- Agent 终身历史钻取页面
- 基础预测下注入口（Mock + CAW 模拟）
- 大屏 Demo 模式
- 清晰的风险边界与 CAW 使用说明

**本周明确不碰的范围**：
- 真实链上 CAW 完整资金闭环
- 多链支持
- 复杂 AI 自主决策
- 重度 3D / 高级可视化

**目的**：确保 Week 4 能交付一个**可完整跑通、可稳定演示**的原型，而不是一个功能多但到处都是坑的半成品。
