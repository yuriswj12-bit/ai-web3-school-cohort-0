# Sponsor Workshop 简记

## 1. Cobo Agentic Wallet Workshop（最相关）

**Sponsor**：Cobo

**解决什么问题**：
Cobo 解决的是 **AI Agent 在真实经济活动中“管钱、花钱、赚钱”的信任与执行难题** 。传统钱包需要人类手动操作或预先授权 API Key，难以让 Agent 真正自主、安全地进行资金操作。Cobo Agentic Wallet（CAW）让 Agent 能在严格权限控制下，自主完成支付、转账、结算等操作。

**提供什么工具**：
- Cobo Agentic Wallet（CAW）
- 权限控制与预算管理功能（单笔/日限额、用途标签、白名单等）
- SDK / API（支持 Agent 自主发起交易）
- 风控与审计日志
- 测试网 / Sandbox 环境

**适合哪个赛道**：
- Cobo 官方赛道：Agentic Economy × Cobo Agentic Wallet
- 任何需要 Agent 真实执行资金操作的项目（支付、交易、资源采购、预测市场、A2A 经济等）

**可以做什么 Demo**：
- Agent 自主使用 CAW 下注/支付（例如在 Agent Economy Live 中，用户或 Agent 对某个服务进行 CAW 预测下注）
- Agent 管理预算并自主采购资源（数据、API、算力）
- 多个 Agent 通过 CAW 完成工作协议的自动结算（发布 → 交付 → 验收 → 付款）
- 展示 CAW 的权限边界控制（预算上限、白名单、用途标签）

## 2. The Graph Workshop（补充）

**Sponsor**：The Graph

** 解决什么问题**：
链上数据查询效率低、实时性差，难以支撑需要高频数据更新的应用（如实时排行榜、活动流、Agent 行为分析）。

** 提供什么工具**：
- Subgraph 开发框架
- GraphQL 查询 + Subscription（实时订阅）
- 托管服务（The Graph Studio）
- 多链支持

** 适合哪个赛道**：
- 需要链上数据实时展示和聚合的项目
- Agent Economy、DeFi、数据分析类赛道

** 可以做什么 Demo**：
- 实时 Agent 交易流 + 排行榜（配合 CAW 资金流数据）
- Agent 终身历史时间轴查询
- 复杂指标聚合（交易量、活跃度、信赖度）
