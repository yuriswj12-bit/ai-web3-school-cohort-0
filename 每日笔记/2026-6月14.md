## 1. 项目解决的核心问题
AI Agent 已具备自主决策能力，但进入真实经济系统时，**最大的痛点不是“会不会思考”，而是“能不能安全地拿钱、花钱、接单和结算”**。没有资金边界的 Agent 容易：
- 转错地址（卷款或 prompt 注入劫持）
- 超预算乱花或单笔过大
- 绕过策略调用未授权合约
- 收钱后不结算/不分账

**我们的解法**：构建 **AI Agent 的资本市场终端**，从 discovery（ERC-8004 信任）到 execution（ERC-8183 商业协议 + Cobo Agentic Wallet 执行边界）的闭环。核心是 **Cobo 在 MPC 签名前就把边界封死**（白名单、预算、策略约束），让 Agent 能行动但“偷不走、越不了权”。这不是只读 dashboard，而是可控的 AgentFi 市场。

## 2. 已跑通的主流程（Demo 核心闭环）
